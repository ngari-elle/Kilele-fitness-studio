# Kilele Fitness Studio — Group Project Report

## Project Overview
We developed a responsive and interactive website for **Kilele Fitness Studio**, a modern fitness studio. The studio offers personal training, group classes, and nutrition guidance. We designed the website for prospective members, fitness enthusiasts, and anyone looking to transform their health in a supportive and motivating environment.

**Live Website:** [https://ngari-elle.github.io/Kilele-fitness-studio/](https://ngari-elle.github.io/Kilele-fitness-studio/)  
**GitHub Repository:** [https://github.com/ngari-elle/Kilele-fitness-studio](https://github.com/ngari-elle/Kilele-fitness-studio)

---

## Website Pages
Our project contains six distinct, linked pages that provide a complete user journey, from learning about the studio to signing up for a membership.

| Page | File | Description |
| :--- | :--- | :--- |
| **Home** | `index.html` | Introduces the studio and the "About Us" section. |
| **Services** | `services.html` | Presents the training services and a full weekly class timetable. |
| **Membership** | `membership.html` | Details the Basic, Premium, and Elite plans with direct links to the sign-up page. |
| **Trainers** | `trainers.html` | Showcases the profiles of our three expert trainers. |
| **Contact** | `contact.html` | Provides a form for general inquiries and messages. |
| **Sign Up** | `signup.html` | A comprehensive portal where users select their service, plan, trainer, and schedule. |

---

## Technologies and Features
We used:
- **HTML5** for the structure and semantic content across all six pages.
- **CSS3** in the shared `style.css` file for styling and responsive layouts.
- **JavaScript** in `script.js` for interactive features.
- **CSS Variables** to maintain consistent colors and brand values.
- **Flexbox** for the header and navigation layout.
- **CSS Grid** for the service cards, membership plans, and trainer profiles.
- **Media Queries** to adapt the layout perfectly to mobile screens (specifically at the `768px` breakpoint).

**Our interactive features include:**
1. A **mobile navigation menu (hamburger toggle)** that opens and closes the drawer when clicked.
2. A **weekly timetable** showcasing classes in a clean, scrollable HTML table on smaller screens.
3. A **responsive background image** with a CSS readability overlay that keeps text clear.
4. **Form validation** on the Sign-Up and Contact pages to ensure required fields are filled.

*Form Note: The Sign-Up and Contact forms are front-end demonstrations. They validate the entered details and display browser feedback, but they are not connected to a backend database and do not store submissions.*

## Responsive Design Evidence
We tested the website using Chrome Developer Tools to ensure it adapts perfectly to different screen sizes.

| Viewport | Result |
| :--- | :--- |
| **375 px (Mobile)** | The navigation collapses into a hamburger menu. Grid cards stack in a single column. The timetable becomes horizontally scrollable. |
| **768 px (Tablet)** | The layout adjusts comfortably, with grid cards expanding. |
| **1280 px (Desktop)** | The full horizontal navigation is visible. Grid sections display three columns. |
